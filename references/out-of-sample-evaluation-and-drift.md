# 样本外评价与非平稳验证知识库

来源：2026 模拟赛 B 题（自来水厂 NTU 预测）问题一复核案例，全部数字经独立重算验证。适用于任何"训练/验证表现正常、测试期崩坏"的非平稳回归题。

## 1. 样本外预测 R² 的口径事实

- 定义 `R²_pred = 1 − Σ(yᵢ−ŷᵢ)² / Σ(yᵢ−ȳ)²`，取值范围 **(−∞, 1]**。样本外为负 = 劣于"恒预测均值"基线，是正常现象，不是计算错误。
- "R²∈[0,1]"只在**带截距、拟合样本内**成立。审稿/队友/老师拿 0–1 说事时，先分清口径。
- **禁止的补救**（都属更改评价口径掩盖失败）：
  - 负值截成 0 或取绝对值；
  - 全文改用 `corr(y, ŷ)²` 冒充 R²——它丢弃全部水平信息，会把"趋势跟着走、数值系统性错"的最危险失败模式洗白（实例：RMSE 0.57 ≈ 4.5×基线，配相关平方仍有 0.23 的"好看"数字）；
  - 只改测试集公式、保留验证集旧公式（混用两种口径）。
- 正确做法：主指标 RMSE/MAE；预测 R² 明确命名（如"样本外预测决定系数"）并在公式后声明取值范围允许负；若需要趋势指标，单独命名 r² 放辅助列。
- 若课程/队伍硬性规定 R²∈[0,1]：删除该列，而不是换定义。

## 2. 朴素基线的判决作用

- 先跑持续性基线（`ŷ_t = y_{t−1}`）和滞后自回归。案例中持续性基线测试集 RMSE=0.127、R²=0.869，完爆 GAM/RF/XGB 全部候选（RMSE 0.43–0.57、R² 全负）。
- **当滞后基线显著优于所有特征模型时，判决是：主要信息在目标自身历史里，纯同刻特征的结构不完备**——应补动态项，而不是调参或换算法。
- 基线行必须进论文对比表；它是"认识数据"的证据，不是丢人的对照组。

## 3. 概念漂移与验证设计

- 分段 Spearman 对照表（train/validation/test 各算一次 feature–target 秩相关）：方向反转即漂移铁证。实例：T/W FLOW +0.368→−0.273，河流水位 −0.225→+0.601，R/W NTU −0.223→+0.565。
- 出界率统计：测试样本落入训练 1–99% 分位区间之外的比例（实例 61%），配合"区间内 vs 区间外"分组 RMSE。
- 单一时间验证窗口在非平稳数据上制造虚假安全感：验证期（9–11月）与训练期规律相似所以通过，测试期（12月）规律反转即崩。修正靠滚动窗口（训至 k 月→验 k+1 月），选型看平均+最差窗口。
- 测试集方差本身小（σ 0.35 < 训练 σ 0.62）会进一步压低一切 R²，解释时须说明。

## 4. 动态修正的能力边界

- 残差 AR（基础静态模型 + AR(p) 残差，p∈{1,2,3,6,12}）：
  - **一步预测有效**（实例：验证 R² 0.766→0.841）；
  - **递推模式几步内衰减归零**，对多步连续缺失无效（实例：测试 R² 完全不变，极端点一个没救回）。
- **部署锚点检查（易漏）**：设计时间修正前，先打开预测期附件看目标列是否有观测。实例：2026 年 2 月附件仅一天 12 个时刻、输入齐全但 **NTU 列全空**，且 2026 年 1–3 月均无锚点 ⇒ 递推必然衰减到零 ⇒ **最终交付的预测数只能来自静态函数部分**，动态修正只改善论文内的评估叙事，不改善交付数字。
- 稳健化变体（输入截尾至训练分位、log1p 目标、更强岭惩罚）实测均救不回结构性负 R²（最好从 −1.18 到 −0.23）。预处理修不了结构缺陷；log 目标是唯一同时小幅改善验证与测试的变体，可作候选但不指望翻盘。
- 少数极端点可贡献总平方误差的一半以上（实例：3 个时刻占 55%）——报告"top-k 点占比"表，把总体 RMSE 与分组 RMSE 并列，否则异常点掩盖常态区间的真实表现（常态区间内 RMSE 仅 0.14）。

## 4b. 交付期目标缺失时的正确结构：锚定-增量模型（2026-08-24 问题三实测定型）

当预测期目标列缺失（无递推锚点）但**交付日前端过程变量实测可得**（如滤后水浊度 FILT 当天有读数）时，正确结构不是静态映射也不是递推，而是：

`ŷ_{a+h} = y_a + f(X_{a+h} − X_a)`，其中 a=交付日已知锚点（实测或前问静态模型代理），增量特征 ΔX 含机理卷积（RTD/停留时间分布）与协变量差分。

实例（问题三，2h 步长，锚=07:00）：
- Δ-Ridge（特征 ΔZ_RTD, ΔFILT, ΔR/W NTU, ΔALUM, Δ流量等 + hour 项）在 2026 跨年外部检验全 horizon 胜平推：12h RMSE 0.167/R² 0.676 vs 平推 0.256/0.241；10h 达 R² 0.858。
- 反冲洗屏蔽（REMARKS 含 B/W 的时点，ΔFILT/ΔZ 特征置 0）把 2025 测试集 R² 从 −0.89 修到 +0.45~0.57：冲洗尖峰不代表出厂水质，属可辨识的操作噪声。
- 线性 Ridge 足够（验证集 Δ-RMSE 0.40 vs XGB 0.60，非线性过拟合漂移更狠）；截尾(0.5%/99.5%训练分位)与折内分位是部署保护。
- 事件验证：2026-01-10 原水突变日，Δ模型正确给出上升趋势（+12h 预测 2.39 vs 实测 1.80），平推纹丝不动（0.25）——这是"协变量修正捕捉突变"叙事的实证锚。
- 敏感性分析落地方式：Δ系数表（FILT +0.73 > Z_RTD +0.41 >> 其余）+ 情景扰动（原水+25%/矾+10%）分 horizon 报告；直接扰动 R/W NTU 12h 内几乎无直接效应（系数≈−0.001），须经 FILT 传导链，与问题二的 6h 时滞一致——两问互相印证。
- 失效残余：12 月真实高浊段（R/W NTU 230–380）NTU 系统性低估约一半幅值；3 月个别单点跳变（03-27）不可预测，用分段报告隔离。

## 5. 第三方复核流程（跨 Agent 审计）

定位材料：`~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl`，按 mtime 排序取目标会话；解析 `type=response_item` 且 `payload.role` 过滤；用户消息跳过 `<environment_context>`/`<recommended_plugins>`/`<user_instructions>` 前缀才是真实请求。大文件先抽取 user/assistant/tool 三类落盘再分析。

复核顺序（由廉到贵）：
1. 从结果明细 sheet **逐行重算**全部指标（不要信汇总表）；
2. 极端点归因：按平方误差排序 top-k，算占比，查对应输入是否越训练分布界；
3. 分段评价：按时间切正常段/事件段分别算指标；
4. 变体压力测试：复刻原版 → 截尾 → log 目标 → 强惩罚，看哪个能救；
5. 动态对照：纯 AR / 联合(特征+滞后) / 持续性基线，确定信息上界在哪；
6. 附件结构核查：最终预测期的目标可用性。
7. **对前一 Agent 开出的药方，必须自己实现跑一遍再采信**——本案例中"残差 AR 修正"处方经实现证明救不了测试集，属半正确诊断。
