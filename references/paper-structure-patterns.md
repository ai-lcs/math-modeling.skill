# 优秀论文结构模式（2025 国赛 C 题三篇样本蒸馏）

来源：2025 年国赛 C 题两篇国一（C023、C132）+ 一篇省一（NIPT 女胎判定），
共 28 / 65 / 80 页，逐页视觉转录后提炼。以下为跨论文共性结构模式，
供写作阶段参照。样本来自同一道题，不能据此要求所有论文采用相同目录、分节、编号或篇幅。优先服从当届模板和当前稿件需要。

## 1. 摘要结构（C023、省一）

- 按"针对问题一/二/三/四"分段，每段独立完整；
- 每段内部顺序：**核心影响因素/方法选择 → 模型/算法名称 → 关键结果（带数字）→ 验证方式**；
- 数字密度高但不堆砌，每个数字都能在正文找到对应结果表；
- 最后一段为"本文亮点"（1-3 句话），不新提方法。

## 2. 章节组织：模型建立与求解分节示例

三篇论文的共性：

| 问题 | 建立节标题 | 求解节标题 |
|---|---|---|
| C023 问题一 | 4.2.x 关系模型建立 | 4.3.x 求解结果 |
| C023 问题二 | 5.2.x 风险评估模型建立 | 5.3.x 动态规划求解 |
| C023 问题三 | 6.2.x 风险评估模型建立 | 6.3.x 改进动态规划求解 |
| C132 问题二 | 7.2.x T_ attain 预测模型 | 7.3.x 多约束下最优策略 |
| C132 问题三 | 8.1.x 数据转换 + 8.2.x 混合深度存续 | 8.3.x 优化模型 + 8.4.x 结果 |
| 省一 | 4.2.x 建立 | 4.3.x 求解结果 |
| 省一 | 5.2.x 建立 | 5.3.x 动态规划求解 |
| 省一 | 6.2.x 建立 | 6.3.x 改进动态规划求解 |

**可借鉴的分工**：建立部分说明假设、变量、公式与约束；求解部分说明算法、代码映射、参数与运行结果。短问或模板受限时也可在同节内分段。

## 3. 公式呈现规范

- 编号连续，不按节重置（三篇均为 (1)-(N) 贯穿全文）；
- 每个公式出现后紧跟 1-3 句解释：变量含义、公式含义、适用条件；
- 复杂公式拆成多步，每步有编号，不一次性塞满整页；
- 正文引用公式时用"(1)"而非"公式 1"或"Eq.1"，保持学术中文习惯。

## 4. 结果呈现：表格为主，图表为辅

- 最优解、参数、分组结果等**精确数值用表格**（带置信区间/阈值标注）；
- 趋势、分布、对比用图（带 95% 置信区间或阈值线）；
- 每个表格/图有编号，正文中出现时立即解释核心信息（不堆"如图所示"）；
- 敏感性/稳健性单独成节（标题固定为"敏感性分析"或"稳健性检验"），用表格呈现多情景结果。

## 5. 附录结构

- 附录 A：文件列表（文件名 + 功能描述，表格）；
- 附录 B：关键数据展示（EDA 图、统计表，与正文引用对应）；
- 附录 C：交互式网页/工程实现（如有）；
- 附录 D：异常/阳性个体清单（表格，含阈值）；
- 附录 E：核心代码（按问题编号分段，每段开头注释功能，不逐段重写说明）；
- 附录 F：补充公式/推导（如有）。

## 6. 模型评价章（第 8/X 节）

三篇均单独成章，包含：
- 优点（3-5 条，每条 1-2 句，对应具体机制）；
- 缺点/局限（3-5 条，对应具体假设或数据限制）；
- 改进方向（与缺点一一对应，或提出下一步工作）。

**评价必须可辩护**：每条优缺点都要能在前文找到依据，不写空泛套话。

## 7. 扫描版 PDF 转录协议

针对扫描版论文（无文本层），逐页转录时的操作规范：

- 使用 `pymupdf` 将每页渲染为 PNG（dpi=95-100）；
- 每页独立调用视觉模型，请求：
  1. 完整转录文字（保持章节层级）；
  2. 公式用文字描述保留编号（如"Y_ij = X_iβ + Z_iβ_i + ε_ij (1)"）；
  3. 注明图表标题与位置；
  4. 附录代码只注明起止与功能，不逐行转录。
- 对于长论文（>40 页），采用 4 页拼图（2x2 montage）减少调用轮次；
- 转录产出仅用于结构分析，不复制独特措辞、数值或未经本题验证的路线。
