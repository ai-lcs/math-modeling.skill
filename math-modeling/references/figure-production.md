## 1. 保持数据含义不变

本参考只用于把已确认的数据和模型结果变成可复现图表。它不授权删除、填补、平滑、插值、重采样、改变口径、隐藏不利结果或重选模型。

对 CSV、Excel、JSON、Parquet 或 Feather 等表格数据，可先运行：

```text
python scripts/profile_tabular_data.py <数据文件> --output <画像.json>
```

该脚本只总结结构、字段、缺失、重复、数值范围和候选时间/分组/空间字段；它拒绝 pickle 等可执行序列化格式，且不产生科学结论。将输出当作读表辅助，仍要核对字段含义、单位、业务规则和数据版本。

对正式 PNG、JPEG、WEBP 或 TIFF 图，可在渲染后运行：

```text
python scripts/audit_figure.py <图片> --code <绘图脚本> --output <审计.json>
```

它检查分辨率、边缘裁切、异常空白、透明背景、显式矢量导出、彩虹色图、双轴、3D 和布局冲突等迹象。它是启发式检查，不验证统计正确性，也不能代替肉眼检查最终尺寸的图片。

## 2. 选择任务路由并形成 Figure Brief

按输入选择最接近的路线：

- 从数据或模型结果新建图：先画像数据，再选图、编码、渲染和审计；
- 改进现有代码：先运行原版并保存基线，锁定正确的数据准备和统计计算，只重构绘图层；若发现计算错误，单独报告；
- 审计现有图片：结合图片、绘图数据和代码检查；没有数据或代码时限制结论，只给可见缺陷和重建计划；
- 迁移参考图风格：提取布局、层级、字体、线型、标记和配色逻辑，不复制参考数据、标签、标识或无依据的科学内容；
- 尚无数据或结果：给图表清单、字段契约和可执行骨架，明确哪些图必须等计算后才能生成，不补造示例结果。

编码前在内部形成 Figure Brief：

1. 信息：读者应该从图中学到的一句话；
2. 证据：支持该信息的字段、变换、统计口径和不确定性；
3. 候选图：两至三个可行形式及各自代价；
4. 选择：最直接暴露关键结构的一种图；
5. 编码：位置、长度、颜色、形状、线型、面积、分面和注释各自代表什么；
6. 去冗余：准备删除哪些重复标题、图例、直接标签、背景块或数值标注；
7. 边界：缺失值、置信区间、阈值、可行域和图不能证明的内容；
8. 输出：最终尺寸、文件名、PNG/矢量格式、代码和绘图数据。

## 3. 采用生产流程

1. 先写内部图表任务卡：图回答的问题、数据与字段、样本范围、单位、预期事实、正文引用和结论边界。
2. 读数据或模型结果，运行数据画像；确认聚合、排序、时间、单位和缺失值没有被误读。
3. 选择能最直接支撑问题的图形，明确使用位置、长度、颜色、形状、线型、面积、分面和注释的含义。
4. 分离计算与制图：`分析或模型脚本 -> 明确结果文件 -> 独立绘图脚本 -> 图片`。绘图脚本不得偷偷重算模型或改变评价指标。
5. 先生成验证图，核对数值映射、轴、图例、单位、类别顺序、矩阵方向和关键点。
6. 生成论文版，导出 PNG 与适用的 PDF 或 SVG；实际查看最终文件，再运行图片审计。
7. 若出现问题，先修科学语义和图形任务匹配，再修裁切、重叠、缺失信息、重复编码和视觉细节。

## 4. 按分析目的选择图形

| 任务 | 首选图形 | 比默认分组柱状图更合适的场景 |
|---|---|---|
| 多类别单指标比较 | 点图、棒棒糖图、水平条形图 | 类别较多、需要排序或强调基线差异 |
| 两状态或前后比较 | 哑铃图、斜率图、连接点图、区间图 | 变化而非两个孤立数值才是重点 |
| 时间与预测 | 折线、阶梯线、区间带、小多图 | 需要区分观测、拟合、验证、预测或缺口 |
| 分布与不确定性 | 箱线、小提琴加散点、ECDF、森林图 | 仅均值会掩盖离散度、样本量或区间 |
| 拟合与诊断 | 真实-预测、残差、误差分布、分面散点 | 需要暴露失效区间和异方差 |
| 多指标模型比较 | 指标-模型热力图、小多图、区间点图、帕累托图 | 指标单位不同、模型较多或存在权衡 |
| 敏感性与稳健性 | 参数曲线、双参数热力图/等高线、龙卷风图 | 参数有顺序、存在阈值、非线性或基准点 |
| 优化与方案 | 可行域、收敛曲线、目标-约束权衡、方案矩阵 | 必须同时展示可行性、基线和权衡 |
| 空间、网络与路径 | 比例符号、差异地图、邻接矩阵、重点路径图 | 原始节点连线太密或区域标准化重要 |
| 构成与流量 | 百分比堆叠、堆叠面积、Sankey、alluvial | 总量或流守恒确实有明确含义 |
| 调度与状态变化 | 甘特图、状态时间线、小多图 | 任务持续时间、资源占用或状态转换是重点 |

优先使用共同尺度上的位置和长度，再考虑角度、面积、颜色和装饰形状。保留时间、空间、序数或题目规定的自然顺序；只有无自然顺序的类别才可按决策量排序。

雷达图、饼图、双纵轴、Sankey、3D 和密集网络图只有在语义明确、替代方案更差且读者不会被误导时才使用。使用时说明归一化、中心值、流守恒、两个轴的关系或筛选规则。

## 5. 服从模型和数据结构

- 模型比较：有重复运行或区间时显示不确定性；不要凭单个不稳定指标强行排序。指标较多时用热力图总览，再用区间点图呈现决策关键指标。
- 敏感性分析：保留参数范围、基准点和可行区；一维有序参数用曲线，双参数用热力图或等高线，局部单因素效应用龙卷风图。
- 预测：明确区分观测、拟合、验证和未来预测区间；缺失时间段保留断口，不连接成貌似观测到的连续趋势。
- 优化：同时展示基线、可行与不可行方案、约束和目标权衡，不只突出赢家；多目标时优先帕累托图或方案剖面。
- 空间：保存坐标参考系和地理语义；区域率用分级设色，原始计数通常用比例符号，避免大区域因面积造成视觉优势。
- 网络与路径：区分候选边、选中路径、方向、容量和重点节点；稠密网络改用邻接矩阵、筛选或分面，不画全边“毛线团”。
- 聚类与降维：说明投影距离不等于原空间距离；没有外部依据时不把簇命名成现实类别。
- 组成与流：只有总量、分区和守恒关系有明确意义时使用堆叠、Sankey 或 alluvial，并说明无法在非共同基线上精确比较的部分。

代表性判断：

- 十二个模型乘六项指标不使用七十二根分组柱；用模型-指标热力图总览，关键指标使用区间点图。
- 有序参数网格不用独立柱状图；用参数曲线标出基准和可行范围，双参数改用热力图或等高线。
- 预测图不同时保留完整图例、直接标签和重复背景标题；选择一套清晰映射并突出观测与区间。
- 路径图不展示全部候选边并给全部节点贴标签；弱化或省略背景边，只突出最终路线和关键约束。

## 6. 让代码可移植、输出可审计

- 使用独立 `.py` 脚本或自包含 notebook 单元，不依赖隐藏的交互状态；
- 显式声明输入、输出、数据准备、随机种子、画布尺寸和样式；
- 把临时变换命名清楚，避免硬编码本应来自数据或配置的数值；
- 对向量友好的图同时保存 PDF 或 SVG；PNG 通常使用至少 300 dpi；
- 检查中文字体回退、负号、透明背景和跨机器可读性；
- 为少数线条且标签不冲突的情形选择直接标注或紧凑图例之一，避免两者完整重复；
- 多子图共享图例、轴标签和尺度的前提是比较语义真的相同；
- 只把有数据或用户依据的方案、阈值和模型用强调色突出。

实现时读取 `references/figure-python-patterns.md`，优先采用独立入口、明确数据准备、可控样式和双格式导出。

## 7. 按 lint 顺序修订

每次渲染后依次检查：

1. 数据、符号、单位、聚合、排序、范围和不确定性是否正确；
2. 图形是否真正回答问题，是否存在更直接的替代形式；
3. 是否有裁切、重叠、错误图例、错误矩阵方向或不可读文字；
4. 是否遗漏基线、阈值、可行域、缺失段、预测区间或样本范围；
5. 是否重复使用标题、图例、直接标签、颜色、背景块和数值注释；
6. 是否让主结论比辅助元素更突出，颜色和网格是否服务信息；
7. 最后才处理阴影、边框、留白等次要外观。

特别避免：

- 用无依据平滑把离散或缺失数据连成连续趋势；
- 因视觉需要截断柱状图零点、删去异常值或隐藏失败模型；
- 把预测区间画成确定结果；
- 以颜色作为唯一编码；
- 用彩虹或 `jet` 色图制造伪边界；
- 在图内、图题和正文重复同一结论；
- 用外观优化掩盖尚未解决的统计问题。
