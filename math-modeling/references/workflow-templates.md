## 1. 按任务规模使用

不要机械展示所有表格。短任务只保留必要字段；多问、多数据源、多人协作或长时间项目才使用完整台账。台账用于防止上下文漂移、静默改口径和结果失去来源，不用于制造文档数量。

## 3. 问题覆盖矩阵

```markdown
| 小问 | 题目动词 | 输入 | 输出 | 目标/约束 | 单位与范围 | 依赖 | 方法 | 证据位置 | 验证 | 直接答案位置 | 状态 |
|---|---|---|---|---|---|---|---|---|---|---|---|
```

状态可用：未开始、进行中、待决定、已运行、已验证、已成稿、已审计。

对多问任务补充接口表：

```markdown
| 上游小问 | 输出量 | 定义与单位 | 不确定性 | 下游小问 | 使用方式 | 接口核验 |
|---|---|---|---|---|---|---|
```

## 4. 证据台账

```markdown
| 编号 | 拟写论断或数字 | 状态 | 证据类型 | 文件/表/图/代码/文献位置 | 可写范围 | 待办 |
|---|---|---|---|---|---|---|
```

证据状态：

- 已证实：可由题面、实际数据、运行输出、已核验原文或用户明确决定定位；
- 待确认：有合理线索但尚未复核；
- 仅建议：尚未实施的模型、分析或写法；
- 不可写：无来源、与材料冲突或超出模型能力。

快速规则：摘要数字定位到正文，正文结论定位到输出或推导，图表定位到数据和脚本，引用定位到原文，建议定位到前文证据。

## 10. 让项目结构与规模相称

单一计算使用一个清晰脚本或 Notebook 即可。多问、多数据源或多人协作时可采用：

```text
project/
  data/
    raw/             # 只读原始数据
    interim/         # 可追溯中间数据
    processed/       # 建模数据
  src/
    common/          # 公共读取、校验与指标
    q1/ q2/ ...      # 各问模块
  configs/           # 参数、种子、路径和划分
  results/           # 机器可读结果与运行索引
  figures/           # 绘图代码、绘图数据和终稿图
  paper/             # 论文源文件与引用
  logs/              # 运行、决策、处理和异常记录
```

不因“规范”创建空目录和无用抽象。结构只服务于协作、审查和复现。

## 11. 管理论文手项目状态与章节合同

只在用户进入论文手主模式或多人协作、长时间续作时使用。短小改写不必机械展示全部模板。

### 论文版本与锁定状态

```markdown
| 项目 | 当前值 |
|---|---|
| 最新实际成稿 | 文件、时间或版本标识 |
| 当前问题/章节 | |
| 当前产物 | 理解卡/标题树/论文母稿/局部回修/终审 |
| 已写入并采用 | |
| 用户亲写或已锁定 | |
| 允许修改 | |
| 已废弃方案、旧图和旧表述 | |
| 当前标题与段落风格参照 | |
| 当前公式、图表和格式参数 | |
| 待向建模手/代码手确认 | |
```

把用户最新实际成稿设为真源。此前 Agent 输出和队友草案只保留为候选历史，防止旧内容静默回流。

### 建模与代码交接映射

```markdown
| 小问 | 建模结论 | 假设/变量/公式 | 数据字段 | 代码变量/函数 | 运行编号与结果 | 图表状态 | 拟放论文位置 | 核验状态 | 待办 |
|---|---|---|---|---|---|---|---|---|---|
```

图表状态可用：候选、用户选中、已插入、已废弃、等待最终版本。不要把代码手中间图当成论文最终证据。

### 章节合同

```markdown
| 项目 | 当前章约定 |
|---|---|
| 本章回答的问题 | |
| 本章直接答案位置 | |
| 上游输入 | 定义、单位、不确定性与来源 |
| 下游输出 | 定义、单位与使用方式 |
| 允许首次引入的概念 | |
| 禁止提前引入或重复的内容 | |
| 核心公式与代码对应 | |
| 结果、图、表和引用证据 | |
| 标题树与各节职责 | |
| 用户亲写/已锁定范围 | |
| 篇幅、格式与交付参数 | |
| 完成判据 | |
```

### 标题树审计卡

```markdown
| 编号 | 层级 | 标题 | 独立职责 | 子标题理由 | 证据槽 | 预计篇幅 | 状态 |
|---|---|---|---|---|---|---|---|
```

检查父标题与第一个子标题之间是否存在游离正文、技术章是否全部平铺为二级标题、三级标题是否孤立或过密、章号和问题号是否与当前任务一致。

### 反馈与回归记录

```markdown
| 日期/轮次 | 用户反馈 | 作用范围 | 本轮处理 | 升级为项目参数或稳定偏好 | 防回归检查 | 状态 |
|---|---|---|---|---|---|---|
```

只把跨项目稳定复现且用户仍确认的要求升级为稳定偏好；把篇幅、图表数、具体开头和公式数量保留为项目参数。
